Версия Python 3.12. Используются только стандартные библиотеки; `requirements.txt` не требуется. `data.json` содержит вымышленные записи.

Запуск из папки `src`:

```bash
python main.py --request R-001
python main.py --request R-002
python main.py --request R-003
python main.py --request R-004
```

`R-001` возвращает статус `review` и два предложения, первым `DEMO-F102` за 1100 с доставкой 4 дня. `R-002` возвращает `clarification` из-за некорректного VIN. `R-003` возвращает `unavailable`: для группы «щетка стеклоочистителя» нет подтверждённой совместимости. `R-004` возвращает предложение проверенного аналога `DEMO-D202` за 2450 с доставкой 3 дня. Статус `review` означает, что менеджер ещё должен проверить применимость, цену и остаток перед отправкой ответа покупателю.
